# Vessel application update — 2026-10-21

This update publishes the latest local vessel application source after the October 19 UWB release.

- UWB following uses relative IMU control with optional confirmed GPS/EKF speed feedback, bounded relative NMPC, improved accepted-measurement timestamp handling, and automatic signal reacquisition. A follow request can wait for a valid signal; operator cancellation still clears recovery intent.
- The configured safety distance remains 0.3 m and the target-loss waiting deadline remains 5000 ms. The relative controller retains braking, actuator limits, heading freshness, and UWB field-of-view checks.
- SIYI A8 mini support includes its command transport, camera relay configuration, UI integration, and the configured UWB-to-camera installation transform. The installation dimensions and approximate camera intrinsics do not establish a completed field calibration.
- Installation and service updates add device environment generation, diagnostics, MediaMTX installation, portable Python service launchers, and map/model preparation tools. Hotspot and Bluetooth credentials use installation placeholders.

## Verification

The release checkout passed 316 JavaScript tests and the project checker covering configuration JSON, JavaScript syntax, Python syntax and unit tests, Shell syntax, and systemd templates. These checks ran locally under Ubuntu 24.04 WSL without connecting to the vessel.

No new hardware deployment, water trial, complete closed-loop following replay, or controlled physical UWB step-response experiment was performed for this publication. Existing following-performance limitations documented in `UWB_RELEASE_2026-10-19.md` remain relevant.

Runtime logs, recordings, backups, generated offline-map tiles, and newly generated model binaries are excluded from this source update. The offline-map manifest and preparation scripts are included; a fresh installation must prepare the required local map data and optional hardware-specific model files. The dependency lockfile is unchanged; dependency audit advisories reported during installation are not resolved by this update.

Rollback is available through the previous release commit `0f20ffa`.
