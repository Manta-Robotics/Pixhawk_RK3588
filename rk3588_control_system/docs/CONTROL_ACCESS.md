# 控制配对与权限

主控制台使用真实的后端配对。公开接口仅有静态页面、`/health`、`/api/auth/status` 和配对入口；其他 `/api` 接口以及 Socket.IO 连接都需要已配对会话。

## 获取设备配对码

安装或升级安装脚本会在 `/etc/manta/manta.env` 中生成一次 `MANTA_CONTROL_PIN`，再次安装保留原值。这是独立的六位控制配对码，与 SSH 密码、Wi-Fi 密码、蓝牙 PIN 不同。维护人员可在可信 SSH 终端查看这一项：

```bash
sudo sed -n 's/^MANTA_CONTROL_PIN=//p' /etc/manta/manta.env
```

直接运行后端且未设置环境变量时，首次启动生成 `data/control-pin`，以后复用该文件。Linux 权限为 `0600`，目录已被 Git 忽略；后端日志不输出配对码。配置的环境变量必须恰好六位数字，否则后端拒绝启动。模拟前端的 `240724` 仅用于 SIM 模式，不能登录真实设备。

更换配对码时，由维护人员修改设备环境文件中的这一项并按正常停机流程重启后端。重启会使所有旧会话失效；不要将环境文件、PIN 文件、会话 Cookie 提交到仓库或日志。

## 操作页面和旁观页面

- 页面配对后创建八小时有效的随机会话，Cookie 使用 `HttpOnly; SameSite=Strict`，HTTPS 下增加 `Secure`。服务重启会清空会话。
- 每个页面有独立标识。只有一个已配对页面可以获取控制权；同一浏览器的其他标签页也不能共享该页面的控制权。
- 后续连接的页面可查看遥测和视频，并显示“只读”。原操作者释放控制后，点击“获取控制”接手。
- 武装、移动、电机、云台、跟随、校准和重启等修改操作都在后端检查控制权。页面标识本身不是登录凭据，必须同时提供有效 Cookie 和对应的实时连接。
- 所有已配对页面保留急停和解除武装能力；未配对客户端不能调用这些接口。
- 自动跟随操作者已断线时，其他已配对页面执行急停或解除武装也会释放保留的控制权，之后可显式接手；在线操作者执行急停后仍保留控制权。
- 旁观页面断开不会影响操作者。手动控制页面最后一个实时连接断开时，后端清零推进和转向并释放控制权；原有命令看门狗仍然生效。
- 已明确启动的自动跟随在网络中断时延续原有行为，并保留原操作者的控制权。自动跟随原有的传感器、测量年龄与失联保护继续生效。主动释放控制、退出登录或八小时会话到期会停止跟随、归零并发送解除武装。
- 同一来源 IP 连续错误配对五次后，锁定至该错误窗口开始后的十五分钟；响应返回 `429` 和 `Retry-After`。

配对鉴权不替代网络链路加密。当前 HTTP/开放热点部署仍应限制在可信网络内；在不可信网络中使用 WPA2 和 HTTPS。

## 维护工具

`scripts/device_api.py`、`status_report.sh`、`check_fc_link.sh`、`measure_uwb_forwarding.py` 和 `test_dual_uwb.py` 使用独立的只读配对会话，读取后退出，不获取控制权。Python 工具依次读取 `MANTA_CONTROL_PIN` 环境变量、可访问的 `/etc/manta/manta.env` 或项目的 `data/control-pin`。远程使用时显式提供设备配对码环境变量；部分工具也支持 `--pin-file`。不要把 PIN 写进命令参数或 URL。

```bash
python3 scripts/device_api.py --url http://127.0.0.1:3000/api/status
python3 scripts/measure_uwb_forwarding.py --seconds 30
# 手动运行后端生成的私有 PIN 文件，也可供 Socket.IO 测量工具使用：
node scripts/measure_uwb_stream.mjs --pin-file data/control-pin --seconds 30
```

Node 流量工具使用 `MANTA_CONTROL_PIN` 或 `--pin-file`。测量进程只接收 UWB 事件，不申请控制、不发送硬件命令，结束时注销自己的会话。

自定义客户端：先 `POST /api/auth/pair`，JSON 为 `{"pin":"设备配对码"}`，保存响应 Cookie；只读请求携带 Cookie 即可。需要修改状态时，还必须建立携带 Cookie 的 Socket.IO 连接，握手提供 `auth.clientId`，并用相同 `X-Manta-Client` 请求头调用 `POST /api/control/claim`。页面标识限 16–80 位字母、数字、`_`、`-`。其他页面持有控制权时返回 `409`，越权修改返回 `403`，未登录或过期返回 `401`。

旧的无会话控制脚本（例如 `measure_face_start.py`）不能继续直接启动或停止硬件。此类操作改用已配对且持有控制权的控制台；不要为兼容脚本添加匿名控制例外。

## 离线验证范围

回归测试使用随机回环端口、虚拟 UDP 飞控桥接及测试配对码，覆盖匿名和旁观者命令拦截、同浏览器标签页隔离、急停、会话撤销、旁观者断开、操作者断开归零及连接取消竞态。测试不打开串口，不连接真实船端。部署后的真实飞控与云台联调仍需现场完成。
