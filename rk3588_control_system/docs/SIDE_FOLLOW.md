# 左右侧伴随

在自动跟随面板选择「后方 / 左侧 / 右侧」，设置侧向间距，再启动跟随。
左右以目标的地面运动方向为准，不以船头或屏幕方向为准。默认间距 2 m，
侧向模式速度上限 0.8 m/s；后方跟随保留原有参数。重启后默认回到后方模式。
位置和间距只能在跟随、启动及自动恢复均停止时切换，选择位置不会武装或启动推进。
左右模式使用传统控制，选择侧向位置会自动切到传统方法，原有 PPO 不用于侧向任务。

## 控制与传感器

`backend/uwb_side_follow.js` 使用可信 UWB 距离/方位、IMU 航向和 GPS/EKF 地速。
先将相对位置旋转到北/东坐标，用自身地速补偿船的移动，对连续测量拟合目标速度。
目标稳定移动至少 800 ms 后建立前进方向；低于 0.2 m/s 时保留最后方向，停止速度前馈。
未建立过方向的静止目标不会触发盲目绕行。GPS、UWB 或时钟中断后重新确认目标运动。

目标方向为 `chi`，右侧单位向量为 `[-sin(chi), cos(chi)]`。
期望船位是目标位置加上左右偏移；期望速度是目标地速加位置误差反馈。
航向与 GPS 航速 PI 复用已有控制器，输出走原有 MANUAL 推进器混控、斜坡和限幅，
侧向控制器不再重复实现一套执行器斜坡。导航有效性复用已有航速环的检查。
船体沿运动方向行进，云台继续独立指向真实目标，不使用虚拟偏移点驱动云台。

侧向模式要求 3D GPS 定位、健康 EKF，以及带时间戳的有效位置、地速、IMU 和 UWB。
航速反馈关闭或导航过期时停止；不退回前向追逐。UWB 失效不使用后方跟随预测或
最后目标点推进。目标身份变化或保护间距不足时保持中立输出，近距离按制动能力降低速度。
不单独实现测量突跳拒收、额外控制时钟状态或切入路线碰撞预测；测量有效性沿用已有上游处理。
侧向参考直接指向期望位置，不提供障碍物绕行；跨到另一侧应先退回目标后方再切入。

`uwb_dual.receiver_fov_half_deg` 仍表示实际接收器覆盖，代码不会扩大天线视野。
配置不足 90 度时拒绝侧向启动，实际目标超出覆盖时暂停推进。当前仓库配置为 90 度，
正侧面处在覆盖边缘，角度抖动或转弯可能触发暂停；稳定并排跟随需要实测侧面余量，
必要时改变接收器安装或增加覆盖。不要只放宽配置来绕过实际盲区。

## API

`POST /api/uwb-follow/mode`，请求体：

```json
{"mode":"left","distanceM":2}
```

`mode` 仅允许 `rear`、`left`、`right`；`distanceM` 可省略，范围 0.5–20 m，
且必须大于既有保护距离加 0.2 m。沿用配对会话、实时控制权和请求来源检查。
`GET /api/uwb-follow/state` 返回可选位置、参数、接收器覆盖；实时状态含
`followMode`、`sideDistanceM`、目标运动方向、期望偏移和位置误差。
启动和停止继续使用原有 `/start`、`/stop` 接口。

`uwb_follow.side_follow` 中的参数范围由配置检查器验证。侧向间距的界面修改仅在本次
后端进程有效，启动时使用配置文件默认值。

## 验证边界

自动化测试覆盖左右几何、航向旋转、自身运动补偿、停下时保持方向、重复测量、
身份切换、过期/异常传感器、中立输出、API 及与后方跟随的兼容。
这些检查不代表完成板端部署或实船水试。首次试验先使用仿真或无人的目标载具，
确认转向符号、实际侧面覆盖、速度环和制动距离后再用于伴随拍摄。
