# 游泳者 UWB 间歇跟随

泳帽标签入水后缺测，出水后恢复。短时缺测期间可使用明确标记的预测目标作为控制参考；不修改 UWB 实测字段、有效标志或时间戳。手动停止、急停、解除武装、飞控失联或等待超时均退出会话，返回测量不会重新武装。

## 状态与默认参数

配置位于 `config/system.config.json -> uwb_follow.prediction`。

| 状态/参数 | 默认行为 |
| --- | --- |
| 正常实测 | 保留原有跟随控制，采集独立观测并估计目标速度 |
| 预测 | 至少 3 个连续观测；最多距最后实测 1000 ms；误差界不超过 0.5 m |
| 预测推进 | 船速不超过 0.35 m/s；油门上限 15%、转向上限 6°，随缺测时间衰减；不增加已有推力，不倒车 |
| 间距约束 | 预测距离减误差界，应大于 1.2 m 加估计停止距离 |
| 等待出水 | 超出预测条件即回中位，保留会话，验证真实推进 PWM 回中位 |
| 恢复 | 3 个新的、连续且合理的测量；800 ms 从零渐进恢复 |
| 长时失联 | 等待状态持续 5000 ms 后退出、解除武装；需操作员重新启动 |

1000 ms 从最后实测计时，5000 ms 从第一次缺测进入等待/预测时计时。前者可能提前受误差或间距约束结束。恢复候选、异常跳变或重复序号不会刷新等待截止时间。短时缺测期间维持已有武装状态，仅在条件允许时发送有限推进；已经解除武装的系统不会自动重新解锁。

## 坐标与观测处理

- 根据校准后的距离、方位和船体航向，将目标转换到局部 NED 固定坐标系。
- 使用健康 EKF 的北/东速度进行短时船体里程积分，再将目标预测转换回当前船体坐标。无需绝对 GPS 坐标，但必须有新鲜、健康的导航速度和姿态。
- 使用有界匀速模型；误差界按初始测量误差、速度不确定度与加速度上界增长。这是工程保守界，不是经水上实验校准的概率置信区间。
- 只有新的完整 DIST+AZ 对更新 `measurementUpdatedAt`；VALID/HB/GOOD 等元数据不能刷新此时间。接收器序号可用时，同时去重序号。
- 船体运动状态不可信时，缺测期间暂停推进。恢复可依靠 3 个连续真实 UWB 测量完成，正常实测跟随不要求 GPS。
- 目标身份改变时退出。模块没有 tagId 时只能检查位置连续性，不能证明回来的测量来自同一游泳者。
- 神经网络使用同一预测结果构造观测，保留实测年龄，并将预测状态的 UWB-valid 输入设为 0。策略模型权重未改动；执行层仍应用共同限幅。

前端以“短时预测跟随 / 等待目标出水 / 定位恢复中”显示状态，并将预测点画成虚线和半透明目标。CSV 增加 `target_source`、`target_last_measured_at`、`prediction_age_ms`、`prediction_uncertainty_m`、`recovery_samples`。

## 验证与调参

运行 `npm run maintenance`，覆盖坐标旋转、船体平移、重复序号、异常测量、重新捕获、真实输出限幅和服务器状态转换。

默认 0.5 m 跟随距离小于预测推进间距门槛，因此在贴近游泳者时，缺测将暂停推进而保留会话。不要单纯扩大超时来继续追踪旧坐标。根据实际断信号分布、推进器响应、漂移、停止距离及佩戴几何重新确定参数。默认减速度 0.3 m/s² 用于估算停止距离，不构成已验证制动性能。

部署顺序：先备份源码与配置，在隔离目录测试；确认解除武装且输出回中位后，更新源码并重启 `manta-bridge` 和 `manta-backend`。首次实机验证应断开动力或移除推进器，检查缺测、重复包、近距离、模式变化、手动停止、急停和超时退出。之后才能在受控水域低速测试。回中位不等于船已停住，仍会有惯性和水流漂移。
