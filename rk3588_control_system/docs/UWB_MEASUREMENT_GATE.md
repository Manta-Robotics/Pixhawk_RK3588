# UWB 原始测量门控与卡尔曼滤波

处理顺序：原始 UWB → 有限数/量程/角度/完整测量对/时效校验 → 与卡尔曼预测比较 → 可信则更新；可疑则仅预测并放大协方差 → 融合可信接收器 → 跟随控制。

## 实现

`backend/uwb_measurement_filter.py` 为每个接收器维护二维笛卡尔匀速卡尔曼模型。每个轴包含位置与相对速度，支持动态时间步长。先用原始距离、方位、安装角度、标定和新鲜船体航向构造观测；再计算创新残差与归一化创新平方（NIS）。角度转换为笛卡尔坐标后比较，避免 ±180° 跳变。模型估计的是接收器相对目标运动；船体转向被补偿，平移通过相对速度建模。外层目标估计仍使用健康 EKF 速度补偿船体平移。

- 首个通过基础校验的观测初始化滤波器，之后才有可比较的轨迹先验。
- 可信：用测量噪声 R 做卡尔曼校正，以 Joseph 形式更新协方差。
- 可疑：不执行校正、不更新最后可信时间、不进入融合稳定性历史；仅推进模型，并将协方差乘以 1.25。
- 缺测：按匀速模型和过程噪声预测，不确定性随时间增长。
- 重复序号：不更新模型、可信时间或接受计数。
- 新目标身份或时钟回跳：旧模型失效；活动跟随会话由现有保护退出。

桥接在 DIST+AZ 完整对到达后进行检测，完整对的两字段时间差不得超过 100 ms。协议提供的 VALID=false 会排除接收器；CRC/LEN 等累计计数仅做诊断，不能充当该帧的测量置信度。未收到完整原始帧，不能用预测数据构造“新测量”。无新鲜航向时不把原始测量用于滤波校正。

## 配置

主配置新增 `uwb_measurement_filter`：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| distance_std_m | 0.12 m | 距离测量噪声标准差 |
| angle_std_deg | 2° | 方位测量噪声标准差 |
| acceleration_std_mps2 | 2 m/s² | 相对运动的过程噪声 |
| initial_velocity_std_mps | 2 m/s | 初始化速度不确定度 |
| nis_threshold | 9.21 | 归一化创新平方门限 |
| absolute_gate_m | 0.6 m | 物理创新门限的基础余量 |
| max_relative_speed_mps | 6 m/s | 相对运动速度上界 |
| rejection_covariance_scale | 1.25 | 每次拒绝后的协方差放大系数 |

除 NIS 外，还要求创新位移不大于基础余量加相对速度上界乘距最后可信测量的时间。各轴使用保守的各向同性测量方差，覆盖径向和横向测量噪声。报告的误差界是两倍位置协方差迹的平方根，并叠加外层运动预测余量；不是经水上实验标定的保证。

`uwb_follow.prediction` 原有 1 秒预测、5 秒等待、间距与速度限制保留。传感器滤波不确定性现在进入该误差判断：拒绝点后不确定性过大，会暂停推进而保留等待会话。连续异常不会靠重置滤波器自动成为可信点；协方差增大后仍需通过创新和物理门限。稳定的 NLOS 偏差或没有先验时的错误初始化，单靠这套检查无法保证识别，仍需现场标定与必要的额外观测。

近期可疑原始距离落入 1.2 m 间距门槛时，也暂停预测推进；它仅有否决推进的作用，不会作为目标坐标参与卡尔曼校正。原始距离有独立更新时间，元数据心跳不能使旧近距离测量重新变新。

## 诊断和验证

每个接收器提供 `measurementStatus`、`filterReason`、`filterNis`、`filterInnovationM`、`filterUncertaintyM`、`rejectedCount`、最后可信时间和原始接收时间。`/api/telemetry` 的 UWB 总体状态增加 `measurementStatus`、`rejectionReason`、`measurementNis`；原始值与可信滤波值保留分离。`/api/uwb-follow/state` 返回当前 measurementFilter 配置。

跟随 CSV 增加测量状态、拒绝原因、NIS 和滤波不确定性。原始诊断来自最近收到数据的已启用接收器；有多个接收器时，同时参考 sensors 中各接收器诊断。一个接收器被拒绝时，仍可融合其他可信接收器。

自动化覆盖原始越界/非有限值、单帧尖峰、噪声收敛、重复包、角度环绕、船体转向、目标变化、协方差正定性，以及真实桥接与融合流程。不启动串口、电机或实际跟随。

修改距离/角度标定或接收器安装参数后，应同时重启桥接和后端，使两个层次使用一致的配置。水上试验前先断开动力验证异常值、缺测、急停和恢复，再低速验证实测残差、拒绝率和误差界。
