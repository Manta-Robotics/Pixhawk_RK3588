# 变更记录

本文件记录面向维护者和部署人员的可见变化。版本发布时，将 `Unreleased` 内容移动到带日期的版本标题下。

## Unreleased

### Added

- 增加按独立测量时钟统计的只读 UWB 流量工具及 40 Hz 传输回归。

- 增加统一的混合语言维护检查，覆盖 JavaScript、Python、Shell、JSON 和 systemd 模板。
- 增加 GitHub Pull Request/Push 自动检查工作流。
- 增加贡献、验证和 PR 记录要求。

### Changed

- UWB 可信点与原始控制目标分离，图示范围延迟缩小；无新鲜定位时仅上次位置点闪烁，身份变化或断连清空。
- 修复摇杆触摸被滚动抢占、多指抢占和中心漂移；窄屏控制区禁止横向滚动。
- 合并高频界面刷新并限制状态请求并发，使用保守板端时钟估计显示测量年龄。

- 扩充 README 的目录职责、运行产物、服务影响和修改边界说明。
