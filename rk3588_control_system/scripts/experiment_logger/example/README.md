# 脱敏实验与录像对齐样例

船体、UWB、云台和识别结果为合成样本。两段带编号画面经过实际编码与成片索引，每段八帧，录制段之间保留断流区间。画面以主机解码时刻对齐，示例未测量实际相机曝光时刻。

- `state_overview.csv` 保留 20 Hz 的样本、来源年龄及当时已到达的识别结果。
- `events.csv` 记录左侧待机后的跟随启用请求与生效，以及同一告警的 UWB 超时和恢复。
- `video_aligned.csv` 以录像段和显示序号对应 `numbered__000001.mp4`、`numbered__000002.mp4`。`frame_*` 保存对应画面的结果，`vision_sample_id` 反映该帧时刻已经能被控制链使用的结果。
- `manifest.json` 保留会话、诊断阈值和录像段映射。定位时按 `clip_id` 与 `display_no` 识别画面。
